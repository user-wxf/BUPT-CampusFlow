一、缓考审批流程

缓考审批流程为：

学生申请缓考 → 辅导员审核 → 学院教务审核 → 缓考申请完成。

如果审核未通过，则申请不会进入后续审批完成状态。

二、学生申请

1. 进入缓考申请页面

学生进入系统后，依次选择：

课程与考试 → 考试管理 → 缓考申请

进入缓考申请页面。

文档示例中，选择活动名称“25-26-2 理论课成绩”后进行查询。在需要进行缓考申请的课程右侧，点击“申请”。

注意：活动名称属于具体学期的界面示例，实际使用时应以系统当前显示的活动名称为准。

2. 填写缓考申请信息

进入缓考申请页面后，需要填写：

缓考原因；

联系方式；

相关附件证明。

文档明确说明：上述项目均为必填项。

填写并上传完成后，点击“确认”。

3. 送审

申请完成后，申请信息的审核状态为“待审核”。

点击操作栏中的“送审”按钮，进入审核人选择页面。

4. 选择审核人

进入选择审核人页面后，勾选审核人。

文档说明：首位审核人为学生所在班级辅导员老师。

选择完成后，点击“送审”按钮。

5. 查询审核结果

审核完成后，学生可以在系统中查询审核结果。

三、学院审批

1. 进入管理端

缓考审批需要在管理端进行操作。

管理端地址：https://jwgl.bupt.edu.cn/

也可以通过信息门户快捷入口进入系统后，通过右上角“切换管理端”进入管理端。

2. 辅导员审核学生缓考申请

学生申请缓考并选择审核人后，审核人进入“学生缓考审核”页面，点击“审核”按钮。

辅导员进入审核信息页面后，可以通过“查看”查看学生申请详情，并进行审批操作：

审核通过；

审核不通过。

如果审核通过，需要选择下一步审核人进行审核，选择完成后点击“提交”。

3. 教务员审核

教务员进入“学生缓考审核”页面，选择相应审核信息并点击“审核”按钮。

进入审核信息页面后进行审核审批操作，操作完成后点击“提交”。

4. 审批结束

审核流程结束后，可以进入“学生缓考管理”查看缓考信息。

四、管理端协助学生进行缓考申请

本节属于管理端/工作人员操作，不是学生本人常规申请流程。

1. 新增缓考信息

进入“学生缓考管理”模块，点击“增加”按钮。

2. 查询学生课程

进入缓考新增页面后：

输入查询学号，或选择学生；

点击“查询”；

查询出学生课程信息。

3. 设置缓考

勾选需要缓考的学生与课程，在页面下方输入缓考原因后，点击“设置”。

文档说明：可以勾选多条数据进行批量设置缓考。

管理端直接添加的缓考信息，无需再进行审核。

RAG 使用提示

本文属于“操作流程型”资料，适合回答：从哪里申请、需要填写什么、是否需要附件、如何送审、首位审核人是谁、在哪里查询审核结果等问题。

关于“哪些情况允许缓考”“必须在何时申请”“未获批准缺考如何处理”等制度性问题，应优先结合《北京邮电大学本科生课程考核与成绩管理实施细则（校发〔2022〕86号）》中的第二十六条。

管理端工作人员操作与学生本人流程应在回答中明确区分，避免把工作人员步骤误当成学生步骤。
